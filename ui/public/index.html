The live gateway inspects MCP JSON-RPC bodies and enforces policy. A future architecture could validate Mcp-Method and Mcp-Name headers against the body, route tools to separate backends, apply independent per-tool limits, and use passive upstream failure isolation. HTTP 200 JSON-RPC tool errors do not automatically count as upstream failures.
